# Government Scheme Finder

## About the project
Government scheme finder is a python-based web application 
developed using Streamlit.It helps users explore government
schemes based on their selected category.

## Features
-Education schemes
-Agriculture schemes
-Business schemes
-Housing schemes
-Official government website links

## Technologies Used
-Python
-Streamlit

## How to Run
1. Install Python.
2. Install Streamlit using pip install streamlit.
3. Run the application using streamlit run app.py.

## Disclaimer
Please visit the official government websites to verify scheme eligibility and application details.
